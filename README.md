# restaurant-order-systems
# Мейрамханаға тапсырыс беру ақпараттық жүйесі

## Жоба туралы
Мейрамханадағы тапсырыс беру, дайындау, жеткізу және төлем 
процестерін автоматтандыратын ақпараттық жүйе.

## Мақсаты
- Тапсырыс беру уақытын қысқарту
- Қателерді азайту
- Клиент қанағаттанушылығын арттыру

## Пайдаланушылар
- Клиент
- Даяшы
- Аспаз
- Әкімші
