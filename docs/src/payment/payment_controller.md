# Төлем контроллері

## Сипаттама
Төлем процесін басқаратын модуль. Қолма-қол, карта және 
онлайн төлем әдістерін қолдайды.

## Функциялар

### processPayment(orderId, method)
Тапсырыс бойынша төлемді өңдейді.

**Параметрлер:**
- orderId (int) — тапсырыс идентификаторы
- method (string) — төлем әдісі

**Қайтарады:** boolean

### generateReceipt(paymentId)
Электронды чек жасайды.

### integrateWithGateway(provider)
Сыртқы төлем жүйесімен интеграция жасайды.

## Қолдайтын төлем әдістері

| Әдіс | Сипаттамасы |
|------|-------------|
| Қолма-қол | Кассир арқылы |
| Банк картасы | Visa/Mastercard |
| Онлайн төлем | Төлем шлюзі арқылы |

## Қауіпсіздік
- SSL/TLS шифрлау
- PCI DSS стандартына сәйкес
