# Функционалдық талаптар

| № | Талап | Сипаттамасы |
|---|-------|-------------|
| FR-01 | Тіркелу/авторизация | Логин/пароль арқылы кіру |
| FR-02 | Мәзірді қарау | Санат бойынша көрсету |
| FR-03 | Тағамды іздеу | Атауы, санаты, бағасы бойынша |
| FR-04 | Тапсырыс беру | Себетке қосып рәсімдеу |
| FR-05 | Асханаға жіберу | Автоматты жіберу |
| FR-06 | Күйді бақылау | Қабылданды → Дайындалуда → Дайын |
| FR-07 | Төлем жасау | Қолма-қол/карта/онлайн |
| FR-08 | Есептілік | Күнделікті сатылым, кіріс |
| FR-09 | Мәзірді басқару | Қосу/өзгерту/жою |
| FR-10 | Хабарлама | SMS/Email/Push |
